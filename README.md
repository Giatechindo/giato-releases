# Giato AI Desktop — Official Releases & Portal

Repository publik ini menyimpan halaman distribusi resmi (**`https://giato.giatechindo.my.id`**), feed pembaruan otomatis (`update.json`), serta installer multi-platform hasil build otomatis:

- **macOS (Apple Silicon):** `.dmg`
- **Windows (x64):** `.exe` (NSIS Setup) & `.msi` (Windows Installer)
- **Linux (x64):** `.AppImage` & `.deb`

Semua installer dikompilasi secara otomatis melalui GitHub Actions (dengan Electron Fuses aktif untuk keamanan binary), disertai checksum `SHA256SUMS.txt` di setiap tag rilis.
