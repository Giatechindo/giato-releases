Frequently Asked Questions

Learn about the Giato AI ecosystem — available as both a dedicated Desktop Workspace and a VS Code AI Extension.

What is Giato? (Desktop App & VS Code Extension) Ecosystem

Giato is a complete local AI coding agent ecosystem created by Gugun Gunawan, S.Kom (Giatechindo) from Subang, Indonesia. It is designed to assist developers in building, refactoring, testing, and shipping code faster while keeping all code 100% private and local.

Giato is available in two powerful formats:

Giato Desktop App

A standalone, calm desktop workspace featuring 2.5D virtual office simulation, AI swarm coordination (Coordinator, Builder, Cloud Ops, Reviewer), multi-project workspace, and local development previews.

Giato VS Code Extension

A native AI coding agent that lives directly inside your VS Code editor. It executes shell commands, inspects files, runs automated test loops, conducts security scans, and guides engineering playbooks directly in your IDE.

Both tools work hand-in-hand to give you full flexibility whether you prefer a standalone environment or in-editor coding.

What is the difference between Giato Desktop and the VS Code Extension? Comparison

Both share the same core AI agent intelligence and privacy-first philosophy, but serve different workflow preferences:

  • Giato Desktop provides a dedicated, tranquil workspace window away from editor clutter. It is ideal for project-level task planning, parallel agent swarms, terminal monitoring, and multi-repository management.
  • Giato VS Code Extension is embedded right into your daily coding flow. It has direct access to your active editor tabs, diff viewer, selection, terminal output, and editor language server.

You can use either one individually or both together depending on your task.

Is Giato free and open source? License

Yes! Giato is open source and free for personal, educational, and commercial development. You can inspect the source code, contribute features, and run it on your machines without subscription paywalls.

For AI model inference, you can bring your own API keys (from OpenAI, Anthropic, DeepSeek, Google) or connect to 100% free local models via Ollama.

How do I install the Giato VS Code Extension? Extension

Installing the extension is simple:

  • From VS Code Marketplace: Open VS Code, press Ctrl+Shift+X (or Cmd+Shift+X on macOS), search for "Giato", and click Install.
  • From VSIX package: You can also download the latest giato-*.vsix package from our GitHub Releases and run code --install-extension giato.vsix.
Which AI models and providers can I use? AI Models

Giato supports a wide variety of state-of-the-art AI providers:

  • Cloud LLMs: Anthropic (Claude 3.5 Sonnet, Claude 3.7 Sonnet), OpenAI (GPT-4o, o1, o3-mini), DeepSeek (V3, R1), Google Gemini (2.0 Flash, 1.5 Pro), and OpenRouter.
  • Local LLMs: Ollama, LM Studio, vLLM, and any OpenAI-compatible local server (e.g., Llama 3.3, Qwen 2.5 Coder, Mistral, DeepSeek-Coder).
Where are my files and code stored? Privacy

Strictly on your local machine. Giato adheres to local-first architecture. Your code repositories, session history, logs, and configuration remain on your computer. Giato never uploads, indexes, or sells your private codebase.

For more details, please review our Privacy Policy.

Which operating systems are supported? Platforms

Giato is fully cross-platform:

  • macOS: Universal installer supporting both Apple Silicon (M1/M2/M3/M4) and Intel processors (macOS 11 Big Sur and newer).
  • Windows: 64-bit installer (.exe and .msi) for Windows 10 and Windows 11.
  • Linux: Portable AppImage and Debian/Ubuntu (.deb) packages for x86_64 architecture.
  • VS Code Extension: Runs on any operating system where Visual Studio Code runs.
Can I use Giato completely offline? Offline

Yes! By connecting Giato (both the Desktop App and VS Code Extension) to a local model runner such as Ollama or LM Studio, all prompt processing and tool completions run on your own hardware without transmitting a single packet over the internet.
